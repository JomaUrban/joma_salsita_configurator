# Odoo 16 – Configurador Salsita (JOMA Mail)

Módulo `joma_salsita_configurator` para Odoo 16: integra el configurador JOMA Mail
de Salsita en la web de Odoo (erp.joma.es → joma.es) y autentica a los clientes
conectados (portal e internos) con un JWT ES256 canjeado por un código de un solo uso.

Instalación: añadir la carpeta de este repositorio al `addons_path`, actualizar la
lista de aplicaciones e instalar «JOMA - Configurador Salsita». Detalles en
[`joma_salsita_configurator/README.md`](joma_salsita_configurator/README.md) y en el
documento de instrucciones para el partner.
